# Shrinkydink
A skill which includes utilities to set up repositories that are compact, safer, and more token-efficient.

Sometimes you have content you want versioned, but not included in your LLM calls. Shrinkydink introduces the concept of the .agentsignore
file to help. It reduces context bloat by allowing user to specifically call out content that should not be included in LLM calls.

This was written with the help of [feat](https://github.com/john/feat), another little uskillity that helps you write nice tight little feature briefs, and then package the brief, the plan, and the implementation all in the same PR.
