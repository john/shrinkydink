# Shrinkydink
A cross-agent skill to help make repositories safer and more token-efficient for agentic coding.

Shrinkydink introduces the concept of the gentsignore file for when you have content you want versioned, but not included in your LLM calls, to reduce unnecessary context bloat. It also creates or edits .gitignore and .gitattribute files to make them agent-friednly./

This was written with the help of [feat](https://github.com/john/feat), another little uskillity that helps you write nice tight feature briefs, and then package the brief, the plan, and the implementation all in the same PR.
